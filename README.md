# backend_codifica-o

06-07-2026 atividade 
Eu consegui transformar a loja que usava localStorage em uma aplicação com Node.js e Express.
Criei o servidor com Express e configurei ele para rodar as rotas da API e também servir os arquivos do front-end sem precisar mexer na interface.
Separei o projeto em partes, criando rotas para produtos, login e carrinho. No CRUD de produtos, consegui fazer listar, criar, editar e excluir usando um array no servidor, sem usar banco de dados.
Com isso, a aplicação passou a funcionar como cliente-servidor, onde os dados não ficam mais no navegador, mas sim no back-end.

Ainda não consegui montar completamente o backend da aplicação com Node.js e Express. Tive dificuldades na criação e organização das rotas de produtos, login e carrinho, e também na implementação da sessão para controlar o usuário logado e o carrinho.
Consegui avançar em algumas partes da estrutura da API, mas o sistema ainda não está totalmente finalizado e integrado como deveria.
